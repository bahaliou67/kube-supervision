# Code de conduite / Code of Conduct

*English below.*

## Français

Ce projet accueille toute personne qui souhaite l'utiliser ou y contribuer,
quels que soient son expérience, son origine, son identité ou ses opinions.

**Attendu** : rester courtois et bienveillant, critiquer des idées et du code
plutôt que des personnes, accepter les retours, aider les nouveaux venus.

**Inacceptable** : insultes, harcèlement, propos discriminatoires, menaces,
publication d'informations privées d'autrui, et tout comportement qui exclut
ou intimide.

**Application** : le mainteneur ([@bahaliou67](https://github.com/bahaliou67))
peut modifier ou supprimer des messages, commentaires, issues et contributions
qui ne respectent pas ce code, et exclure temporairement ou définitivement une
personne du projet.

**Signalement** : par message privé au mainteneur sur GitHub, ou via le
[signalement privé](https://github.com/bahaliou67/kube-supervision/security/advisories/new)
du dépôt. Les signalements sont traités avec discrétion. Une faille de
sécurité suit la procédure de [SECURITY.md](SECURITY.md).

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org).

## English

This project welcomes everyone who wants to use it or contribute to it,
regardless of experience, background, identity or opinions.

**Expected**: be courteous and kind, criticize ideas and code rather than
people, accept feedback, help newcomers.

**Unacceptable**: insults, harassment, discriminatory remarks, threats,
publishing other people's private information, and any behavior that excludes
or intimidates.

**Enforcement**: the maintainer ([@bahaliou67](https://github.com/bahaliou67))
may edit or remove messages, comments, issues and contributions that do not
follow this code, and temporarily or permanently ban someone from the project.

**Reporting**: by private message to the maintainer on GitHub, or through the
repository's [private reporting](https://github.com/bahaliou67/kube-supervision/security/advisories/new).
Reports are handled discreetly. Security vulnerabilities follow
[SECURITY.md](SECURITY.md).

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org).
